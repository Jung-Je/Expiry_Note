# 만료노트

> 계약, 구독, 보증 등 놓치기 쉬운 만료 일정을 한곳에서 관리하고 알림받는 웹·앱 서비스

## 프로젝트 소개

만료노트는 일상에서 관리하기 어려운 각종 만료일과 결제 일정을 등록하고 관리하는 서비스입니다.

사용자는 계약, 구독, 보증, 멤버십 등의 정보를 등록하고 만료일 또는 결제일이 다가오기 전에 알림을 받을 수 있습니다.

웹과 모바일 앱을 함께 제공하여 언제 어디서나 일정을 확인하고 관리할 수 있도록 하는 것이 목표입니다.

## 개발 배경

일상에서는 다음과 같은 날짜를 놓치기 쉽습니다.

- 정기 구독 결제일
- 계약 종료일 및 갱신일
- 제품 보증 만료일
- 멤버십 만료일
- 보험 및 각종 서비스 갱신일

이러한 일정은 여러 서비스와 문서에 흩어져 있어 한 번에 확인하기 어렵습니다.

만료노트는 흩어진 만료 일정을 하나의 서비스에서 관리하고, 필요한 시점에 알림을 제공하여 불필요한 결제나 갱신 누락을 줄이는 것을 목표로 합니다.

## 주요 사용자

- 여러 정기 구독 서비스를 이용하는 사용자
- 계약 종료일과 갱신일을 관리해야 하는 사용자
- 제품 보증기간을 기록하고 싶은 사용자
- 멤버십과 보험 갱신일을 놓치고 싶지 않은 사용자
- 만료 일정을 한곳에서 관리하고 싶은 사용자

## 요금제

### 무료 플랜

- 제한된 수의 만료 항목 등록
- 기본 만료 알림
- 일정 및 통계 확인

### 프리미엄 플랜

- 월간 구독 방식
- 현재 기획 가격: 월 2,900원
- 만료 항목 무제한 등록
- 맞춤 알림
- 월간 결제 및 언제든 해지

> 월 2,900원은 현재 기획 단계의 가격이며, 실제 출시 전 최종 확정할 예정입니다.

## 주요 사용자 흐름

## 프로젝트 구조

모노레포로 관리하며, 스택이 확정된 영역부터 순차적으로 채워 나갑니다.

```

├── backend/     # Django + DRF API 서버 (uv 관리)
├── frontend/    # 웹 프론트엔드 (Vite + React, DRF API 연동)
├── mobile/      # 모바일 앱 (스택 미정)
```
